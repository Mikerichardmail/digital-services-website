## 1. Overview of Source Categorization

All technical benchmarks, algorithmic thresholds, and implementation rules in the `SEO-RULES/` library are anchored in verifiable documentation. Sources are classified into three authority tiers:

1. **Official Documentation (`[OFFICIAL]`):** Direct documentation from search engine developers and web standards bodies (Google Search Central, Google Search Essentials, Microsoft Bing Webmaster, W3C, WHATWG, IETF RFCs, Schema.org).
2. **Industry Research & Empirical Case Studies (`[INDUSTRY]`):** Large-scale statistical studies, SERP click-through-rate analyses, and engineering whitepapers published by recognized search technology platforms (Ahrefs, Semrush, Moz, Backlinko, Search Engine Land, Search Engine Journal).
3. **Framework & Platform Technical Docs (`[PLATFORM]`):** Official developer documentation for the HelpIt technology stack (Astro.build, Cloudflare Workers & Pages, Tailwind CSS, Google Chrome DevTools).
